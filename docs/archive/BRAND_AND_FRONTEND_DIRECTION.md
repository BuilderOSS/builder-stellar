# Earlier frontend direction: historical extract

The full earlier direction is retained at `cbe5ce7:docs/BRAND_AND_FRONTEND_DIRECTION.md` in Git. It positioned Builder as the gateway to independently governed DAO workspaces and separated launch-admin Setup from governance-controlled management.

Its graphite/near-black, Stellar-blue, Inter-led visual direction and proposed lobby/marketplace delivery phases are not the current visual specification. The current system is Warm Ink · Dusk: light, dark and system appearance, Bricolage Grotesque for display, Figtree for interface text, one blue for actions and brass for what's yours ([DESIGN.md](../../DESIGN.md)). Public collaboration/tags and a full onboarding tour were not established by the old plan.

Use [current frontend direction](../BRAND_AND_FRONTEND_DIRECTION.md) and [web behavior](../../apps/web/README.md). This historical extract is not a current runbook or a claim that all earlier proposals shipped.
