## Overview

The tribe profile is what people see first: the name, symbol, image, description, and links. This guide shows how to change it in **Manage → Tribe profile**, both during setup and after launch.

## Before you start

- **During setup**, the [launch admin](/reference/glossary#launch-admin) changes the profile directly. Connect the launch admin wallet. Each change is a direct transaction.
- **After launch**, changes require DAO governance. Any connected wallet can add them to a proposal draft, and they apply only if members vote for them. To submit the proposal, you need enough votes. See [Write a proposal](/guides/proposals/write/).
- Connect your wallet on the tribe's network. Testnet is the live network today.
- Have the new image ready, if you are changing it: a PNG, JPEG, WebP, or GIF file.

## Steps

1. **Open Tribe profile.** Choose **Manage** in the tribe's navigation, then **Tribe profile**. The page is headed "How people see" and the tribe's name.

   <Shot id="manage/profile/01" alt="The Tribe profile page with the image, name, symbol, link and description fields" />

2. **Change the image.** Choose **Choose image** and pick a file. A preview appears. Choose **Upload image** to include it. The new image is used only after it is uploaded.

   <Shot id="manage/profile/02" alt="A new image preview with the Upload image button beneath it" />

3. **Change the name or symbol.** Edit **Name** (up to 40 bytes) and **Symbol** (up to 10 capital letters or digits). These are also the membership token's name and symbol. Every changed field shows **Changed** with an **Undo** button.

   <Shot id="manage/profile/03" alt="The Name and Symbol fields with the Changed label and Undo button" />

4. **Change the description and links.** Write in **Description**, which accepts Markdown. Under **Links**, choose **Add a link**, then enter a label, such as "Website", and an address. You can add up to 8 links. Each address starts with https://, http://, mailto:, or ipfs://. The description, links, and image together can use up to 4,096 bytes.

   <Shot id="manage/profile/04" alt="The Description field and two labelled links under Links" />

5. **Check what will happen.** The box at the bottom lists each change. During setup it is headed **This will**. After launch it is headed **If the proposal passes, it will**. For example: **Rename the tribe**, then **Update the profile**.

   <Shot id="manage/profile/05" alt="The plan box listing Rename the tribe and Update the profile" />

6. **Apply or add to a proposal.** During setup, choose the button that names the changes, for example **Apply 2 changes now**. Your wallet asks you to sign each change in turn. After launch, choose **Add 2 actions to proposal**. The changes join your proposal draft, and nothing is signed yet.

   <Shot id="manage/profile/06" alt="The button Add 2 actions to proposal with the line Requires DAO governance beneath it" />

### Changing the link

The **Link** field sets the tribe's address, /dao/ followed by the link. During setup it changes with the other fields, but the new link is reserved for your tribe only when it launches. After launch, a link change needs its own proposal, because a link that another tribe takes first would make every other action in the same proposal fail. The plan box shows it as **In its own proposal: change the link**, with its own **Add the new link to proposal** button. See [Set up: your link](/guides/setup/slug/).

## What happens on chain

<Disclosure title="Contracts, fees and waits">
  The name and symbol are stored on the tribe's Token contract (`set_metadata`). The description, links, and image are saved together as one profile by the tribe's Metadata contract (`update_profile`), which publishes the profile in an event and stores its hash. The image itself is uploaded first, and the profile holds its address. The link is stored by the platform's Manager contract: `update_pending_slug` during setup, and `change_slug` after launch.

  The profile update names the revision it replaces. If someone else changes the profile first, the update fails, so one change can't overwrite another by accident.

  During setup, only the launch admin can make these calls. At launch, control passes to the tribe's Treasury, so after launch each change runs only as part of a proposal that passes and is executed.

  Each transaction costs a Stellar network fee in XLM. Tribe Builder takes no fee. The profile is public on chain once the change is confirmed.
</Disclosure>

## If something goes wrong

- **"Read only."** This wallet can't change the profile. During setup, connect the launch admin wallet. After launch, connect any wallet to build a proposal.
- **"The profile changed since this page loaded."** Someone changed the profile after you opened the page. Reload the page, review the current profile, and make your changes again.
- **"Profile exceeds the 4,096-byte limit."** Shorten the description or remove a link.
- **"Upload the new image to include it."** You chose an image but didn't upload it. Choose **Upload image**.
- **"The current profile can't be shown right now."** The app couldn't check the profile against the chain. Saving a new description, links, or image replaces the current one, so check carefully before you continue.
- **A link field shows an error.** Give each link a label of up to 32 characters, and start the address with one of the accepted prefixes.
