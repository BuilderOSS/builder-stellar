When a transaction fails, the app shows a plain message followed by a code, for example "The bid is below the minimum next bid. (code 7407)". This page lists every code, grouped by the contract that raises it, with what to do next.

Most failures are caught before you sign. The app simulates each transaction first, so a failure usually means nothing was signed or submitted, and nothing changed on chain.

## How codes work

Each Tribe Builder contract owns its own block of 100 codes, so a code alone tells you which contract raised it, even when one contract calls another.

| Codes | Contract |
|---|---|
| 1000 to 1099 | Pause switch (a shared library used by the auction and the market) |
| 5000 to 5099 | Voting (the shared governor library) |
| 7001 to 7099 | Shared checks used by every Tribe Builder contract |
| 7101 to 7199 | Manager, the platform contract that creates and launches tribes |
| 7201 to 7299 | Token, the membership tokens |
| 7301 to 7399 | Metadata, the artwork and tribe profile |
| 7401 to 7499 | Auction |
| 7501 to 7599 | Governor, Tribe Builder's own proposal rules |
| 7601 to 7699 | Treasury |
| 7701 to 7799 | Marketplace |
| 7801 to 7899 | Claims, the claim lists |

A code that is missing from these tables is retired or unused. Codes are never reused for a different meaning.

## Proposals and voting

These come from the shared governor library and from Tribe Builder's Governor.

| 5001 | A proposal with exactly the same actions and description already exists. | Change the description or the actions, or vote on the existing proposal. |

| 5006 | The proposal didn't pass, so it can't be queued. This also appears if it's already queued. | Check the proposal's status. |

| 5008 | The proposal has already run. | Nothing to do. |
| 5009 | The proposal can't be cancelled. Only the person who made it can cancel, and only before voting ends. | See [Cancel a proposal](/guides/proposals/cancel). |

| 5021 | The proposal description is too long. | Keep the description to 4,096 bytes or fewer. |
| 7501 | The safety delay is shorter than 5 minutes. | Choose at least 5 minutes. |

| 7503 | Quorum is outside 0.01% to 100%. | Choose a quorum in that range. |
| 7504 | The wait before voting opens is shorter than 5 minutes. | Choose at least 5 minutes. |
| 7505 | Voting stays open for less than 5 minutes. | Choose at least 5 minutes. |
| 7507 | Proposals run through the Treasury, not the Governor. | Use Execute on the proposal page, which calls the Treasury. |
| 7508 | A proposal has more than 20 actions. | Split it into two proposals. |
| 7509 | The wait before voting opens is longer than 30 days. | Choose 30 days or less. |
| 7510 | Voting stays open for longer than 30 days. | Choose 30 days or less. |
| 7511 | The safety delay is longer than 30 days. | Choose 30 days or less. |
| 7512 | You had no votes when this proposal was made, so you can't vote on it. | Votes delegated to you after a proposal is made count only on later proposals. See [Votes and delegation](/concepts/votes-and-delegation). |

| 7518 | The Governor's code and its stored data are from different releases: a migration is due after an upgrade. | Run the Governor's migration once. Anyone can run it, and it needs no proposal. See [Upgrades](/concepts/upgrades). |

## Codes you should not normally see

These mean that a contract is wired up incorrectly, or that a transaction was built by hand. The app does not build transactions that cause them. If you see one, note the code and the transaction hash, and report it to the Tribe Builder team.

| Code | Meaning |
|---|---|
| 7003, 7004, 7008, 7009, 7010, 7011, 7013 | A required contract setting (Manager, running version, admin, Treasury, Governor or storage version) is missing. |
| 7007 | The release can't be found. |
| 7101, 7102, 7104, 7106, 7107, 7109, 7124 | Platform registry checks: a release name, version or hash is wrong, already withdrawn or already registered, or the platform admin is missing. |
| 7203, 7302, 7414, 7506, 7601, 7711, 7830 | The Treasury given doesn't match the one the contract was created with. |
| 7208 | The token has no metadata contract. |
| 7301, 7413, 7701 | The contract was never set up. |
| 7410 | The caller is not allowed to do this. |
| 7411, 7710 | A calculation overflowed. |
