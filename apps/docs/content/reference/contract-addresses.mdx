Tribe Builder runs on Stellar testnet. Test XLM has no value, and tribes on testnet are for trying the product. There is no mainnet deployment yet.

## How the contracts fit together

Each site has one **Manager**, the platform contract that creates tribes, launches them, and keeps the list of approved contract releases.

Each tribe then has its own contracts: a token, a governor, a treasury, metadata, and the modules it chose, such as an auction, a market or claims. Their addresses are different for every tribe. To find them, open the tribe and expand **Technical details** at the foot of its home page, or **Contracts** in the tribe's **More** menu.

A new tribe is created from the releases the Manager lists as current. A tribe moves to a newer release only by its own vote. See [Upgrades](/concepts/upgrades).

## Check a contract yourself

Every address on this page and in the app links to [stellar.expert](https://stellar.expert/explorer/testnet), a public Stellar explorer. There you can see a contract's code hash, its storage, and every transaction that called it. A tribe's contracts should run one of the code hashes listed above, or a later release the Manager has approved.
